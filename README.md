Entry for the [One-Line Laugh Sprint](https://make.fun/bounty/u-daring-gecko-25-one-line-laugh-sprint-cda708b2) on make.fun: one original funny line (max 200 characters) on a light, funny take on everyday life.

`main.py` (Python standard library only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`. It is deterministic: every run writes byte-identical output.

The line:

> My bank app sent me a spending summary: apparently I've been investing heavily in snacks and regret.
